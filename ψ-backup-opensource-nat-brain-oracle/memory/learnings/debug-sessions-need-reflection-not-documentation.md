# Principle: Debug Sessions Need Reflection, Not Documentation

**Date**: 2026-03-10
**Source**: Prune cycle 11, Agent 4
**Tags**: pruning, debugging, reflection

## Pattern

"I documented my debugging session" is not a learning. Transferable wisdom requires reflection on the pattern, not just the fix.

## Test

"Could someone in a different project use this?" If the answer requires knowing the exact codebase → it's a project note, not a learning.
