# Principle: Meta-Principles Need Consolidation Too

**Date**: 2026-03-10
**Source**: Prune cycle 17, Agent 5
**Tags**: pruning, meta, consolidation

## Pattern

Pruning cycles that create principles each run generate their own redundancy. 10 principles saying "session notes are transient" in different words is the same anti-pattern we're pruning. Consolidate principle families to one authoritative statement.
