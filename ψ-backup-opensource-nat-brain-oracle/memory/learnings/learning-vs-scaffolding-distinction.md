# Principle: Learnings vs Scaffolding

**Date**: 2026-03-10
**Source**: Prune cycle 12, Agent 2
**Tags**: pruning, knowledge-management

## Pattern

Genuine learnings come from solving problems and discovering patterns through experience. Organizational scaffolding — inventories, catalogs, changelogs — documents state without interpretive depth.

## Test

"Does this file explain WHY something matters, or just WHAT exists?" If just what → scaffolding, not learning.
