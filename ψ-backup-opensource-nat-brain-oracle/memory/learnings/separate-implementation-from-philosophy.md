# Principle: Separate Implementation from Philosophy

**Date**: 2026-03-10
**Source**: Prune cycle 15, Agent 5
**Tags**: pruning, oracle-v2, philosophy

## Pattern

oracle-v2 was an experimental iteration. Its technical decisions (Drizzle ORM, FTS5 queries, PM2 configs, tray UI) belong in project history, not eternal knowledge. Filter implementation logistics from transferable philosophy.
