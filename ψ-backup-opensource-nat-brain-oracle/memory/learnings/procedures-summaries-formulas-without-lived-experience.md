# Principle: Procedures Without Lived Experience Are Not Learnings

**Date**: 2026-03-10
**Source**: Prune cycle 11, Agent 5
**Tags**: pruning, imports, experience

## Pattern

Imported procedures, tutorial summaries, and technical formulae without integrated personal discovery are reference material, not learnings.

Knowledge entries that are procedures, imported summaries, or technical formulae without a personal "I discovered this when..." narrative belong in documentation, not in the learning memex.
