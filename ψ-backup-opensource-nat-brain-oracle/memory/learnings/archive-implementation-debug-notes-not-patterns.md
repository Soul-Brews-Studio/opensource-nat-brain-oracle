# Principle: Archive Implementation Notes, Keep Patterns

**Date**: 2026-03-10
**Source**: Prune cycle 12, Agent 3
**Tags**: pruning, debugging, transferability

## Pattern

Implementation notes tied to specific builds should be archived. Only retain patterns that transfer across projects. "I fixed X in oracle-v2 v0.3.2" is a debug note. "When Y happens, check Z" is a pattern.
