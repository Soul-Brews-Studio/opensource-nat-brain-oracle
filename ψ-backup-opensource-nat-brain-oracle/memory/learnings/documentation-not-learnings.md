# Principle: Documentation ≠ Learning

**Date**: 2026-03-10
**Source**: Prune cycle 11, Agent 1
**Tags**: pruning, knowledge-management, philosophy

## Pattern

Tool documentation disguised as learnings pollutes the memory system. Reference guides belong in `.CLAUDE.md` or tool repos, not in experience-based learnings.

The learning memex should capture insights gained FROM USING tools, not describe the tools themselves.

## Test

"Did I learn this from friction, or did I copy it from a manual?" If copied → reference material, not a learning.
