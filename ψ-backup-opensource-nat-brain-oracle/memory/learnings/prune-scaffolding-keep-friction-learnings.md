# Principle: Prune Scaffolding, Keep Friction Learnings

**Date**: 2026-03-10
**Source**: Prune cycle 13, Agent 5
**Tags**: pruning, scaffolding, experience

## Pattern

Numbered files (000-*), indexes, and organizational scaffolding represent system structure, not lived experience. True learnings capture "what I learned when something broke" — they come from friction, not filing systems.
