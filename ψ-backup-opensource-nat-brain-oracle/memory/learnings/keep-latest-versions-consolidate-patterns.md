# Principle: Keep Latest Versions, Consolidate Patterns

**Date**: 2026-03-10
**Source**: Prune cycle 11, Agent 3
**Tags**: pruning, versioning, consolidation

## Pattern

When multiple files cover the same topic at different levels of maturity, keep the highest-version and most comprehensive variant. Delete earlier iterations that are fully subsumed by broader patterns.

v1.00 → v2.00 = delete v1.00. Single-issue fix → comprehensive guide = delete the fix.
