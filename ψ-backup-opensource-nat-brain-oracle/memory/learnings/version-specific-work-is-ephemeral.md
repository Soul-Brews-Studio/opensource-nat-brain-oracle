# Principle: Version-Specific Work Is Ephemeral

**Date**: 2026-03-10
**Source**: Prune cycle 16, Agents 2 & 3
**Tags**: pruning, versions, ephemeral

## Pattern

Release checklists, version milestones, answer keys, hardware configs, and deployment guides are tied to specific versions. Once superseded, they have no forward value. Working implementations and principles endure; version numbers don't.
