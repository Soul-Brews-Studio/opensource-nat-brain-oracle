# Principle: Delete Transient Logs, Keep Pattern Wisdom

**Date**: 2026-03-10
**Source**: Prune cycle 14, Agent 4
**Tags**: pruning, transience, wisdom

## Pattern

Mid-development files documenting transient issues, tool workarounds, and meta-analysis don't transfer value. Pattern learnings belong in active docs. Session logs belong in retrospectives, not learnings.
