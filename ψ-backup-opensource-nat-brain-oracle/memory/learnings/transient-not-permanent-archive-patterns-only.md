# Principle: Transient Content Is Not Permanent Knowledge

**Date**: 2026-03-10
**Source**: Prune cycle 15, Agents 1 & 4
**Tags**: pruning, transience, permanence

## Pattern

Version-specific releases, one-time debugging, time-bound instructions, and personal timeline logs have transient value. Once core patterns are documented elsewhere, session notes become noise. Tool guides and skill studies are absorbed into living code.
